# Pipeline calibration scripts

Copy the following files from the `pose2sim-preprocess` repo into this directory:

- `calibrate_intrinsics.py`
- `calibrate_extrinsics.py`
- `setup_pose2sim_project.py` → rename to `setup_project.py`
- `sync_videos.py`
- `inspect_calibration.py`

These scripts are not yet on PyPI. Install the repo locally or via git URL.
